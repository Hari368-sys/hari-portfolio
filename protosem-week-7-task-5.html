Firebase Logging, Automation & Data Export

The complete system: automatic LDR lighting, Firebase data logging, charts and CSV export.

← Week 7Task 1Task 2Task 3Task 4Task 5

01Overview

This task completes the system. The ESP32 turns the light on automatically when the LDR reports darkness, logs every reading with a timestamp to Firebase, and the dashboard plots the history as charts and exports it as a CSV file.

02Concepts

Automatic lighting

A threshold on the LDR reading decides when the bulb switches on or off, with no user action.

Data logging

Each reading is stored with a timestamp under a log node, building a history.

Charts and CSV export

The dashboard reads the log, draws charts of the values over time, and builds a CSV file the user can download.

03System Design

LDR and sensors→ESP32 (threshold logic)→Relay and bulb→Firebase log→Charts and CSV

04Hardware & Software

Hardware

  • ESP32 development board
  • LDR with a fixed resistor
  • DHT11 sensor (optional)
  • Relay module and bulb with holder

Software & platforms

  • Arduino IDE
  • Firebase Realtime Database
  • Chart library for the dashboard (for example Chart.js)
  • Browser CSV download
